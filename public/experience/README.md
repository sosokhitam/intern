## Spesifikasi gambar

- Rasio **16:10** (mis. `1200 x 750` px)
- Format `.jpg` atau `.webp`
- Ukuran file < 300 KB
- Contoh foto: sesi mengajar di lab, foto tim/cohort, sertifikat kegiatan,
  dokumentasi kegiatan himpunan

Jika file belum ada, tampil placeholder rapi — tidak error.
