# Folder Screenshot Project

Taruh screenshot project di folder ini, lalu tulis path-nya di
`src/data/projects.js` pada field `image`.

Contoh:

```js
image: "/projects/aksesara.png",
```

## Nama file yang sedang dirujuk (belum ada — silakan tambahkan)

| File             | Untuk project |
| ---------------- | ------------- |
| `aksesara.png`   | Aksesara      |
| `assetify.png`   | Assetify      |

> SisaBisa, OrderQ, dan Clean Area sudah memakai gambar dari
> `src/assets/Project/`, jadi tidak perlu ditambahkan di sini.

## Spesifikasi gambar

- Rasio **16:10** (mis. `1600 x 1000` px)
- Format `.png` atau `.webp` (webp lebih ringan)
- Ukuran file ideal < 400 KB
- Screenshot halaman utama / dashboard, hindari data pribadi asli

Selama file belum ada, kartu project otomatis menampilkan placeholder — jadi
website tetap berjalan normal tanpa error.
